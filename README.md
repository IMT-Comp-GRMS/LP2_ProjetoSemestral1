Este projeto nasceu como uma solução prática para um trabalho de empreendedorismo e gestão, desenvolvido sob medida para a Velato, uma marca de calças com zíper interno. Trata-se de uma interface inteligente baseada no método Kanban, projetada para transformar e acelerar a gestão logística de operações de e-commerce.

**O que a aplicação oferece?**
Uma visão centralizada e visual de toda a jornada do pedido, eliminando a dependência de planilhas confusas e unificando o fluxo de ponta a ponta.

Principais Benefícios:
Agilidade nas Entregas: Reduz o tempo entre a compra e o envio, aumentando a satisfação do cliente final.
Visão Estratégica: Facilita o controle de estoque e a tomada de decisões rápidas por parte dos gestores.
Funcionalidades para o Usuário Final:
**Fluxo em 5 Etapas Operacionais:** Acompanhamento visual do status do pedido: Recebido ➔ Pagamento Confirmado ➔ Separado ➔ Enviado ➔ Entregue.
**Criação e Gestão de Pedidos:** Cadastro rápido de novas vendas com seleção direta dos produtos.
**Classificação de Prioridades:** Destaque visual para pedidos urgentes passarem na frente do fluxo de separação.
**Histórico de Vendas:** Consulta rápida e organizada de todos os pedidos já finalizados.

Por que utilizar? Porque ela une a simplicidade visual do Kanban com a precisão necessária para o e-commerce faturar mais e errar menos.
